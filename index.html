Kigali City Land Use / Land Cover — Esri 10 m Sentinel-2 (2017 · 2021 · 2025)

A step-by-step workflow to map and compare land cover across Kigali City for three years using the Esri / Impact Observatory 10 m annual land-cover time series in Google Earth Engine — with per-class area statistics, change detection, downloadable rasters and styled vector layers, an interactive app with download buttons, and a print-ready QGIS map complete with north arrow, legend and embedded charts.

Platform: GEE Code Editor (JavaScript) + QGIS Dataset: Esri 10 m Annual LULC (Impact Observatory) Resolution: 10 m · Sentinel-2 AOI: Kigali City (3 districts) Years: 2017, 2021, 2025 Output: Maps · Charts · Raster + Vector · App · Print layout

This session uses the Esri 10 m Annual Land Cover product, produced by Impact Observatory for Esri from ESA Sentinel-2 imagery. Each annual layer is a composite of deep-learning predictions across nine land-cover classes, giving a representative snapshot of the year with an assessed accuracy above 75 %. Because it is a consistent annual time series, it is well suited to multi-year comparison — here 2017, 2021 and 2025 — using one classification scheme throughout.

What you will build: Esri land-cover maps for 2017, 2021 and 2025 clipped to Kigali City in the official Esri colours; per-class area tables and bar charts for each year; a class-transition change layer; class polygons vectorised and exported with their colours baked in; a published app titled "Kigali Esri Land Cover Explorer" with buttons that download the data; and a QGIS print layout with a north arrow, scale bar, legend and area chart for your report.
Academic honesty note: This guide gives the complete method and reproducible code. It does not pre-fill result numbers (e.g. "built area grew by X km²"). You generate every figure by running the scripts on live data, then report what you actually observe. Not every requested feature lives in the same tool — the GEE vs QGIS capability table is explicit about which platform produces the north arrow, the print layout and the styled vector download, so nothing here overstates what a single tool can do.

Esri land-cover classes & official colours

The product uses nine classes. The raw class values are non-sequential (1, 2, 4, 5, 7, 8, 9, 10, 11) — an intentional design that leaves room for sub-classes. These exact values and hex colours are what you apply in both GEE and QGIS so your maps match the official Esri styling.

ValueClassColour (hex)
1Water#1A5BAB
2Trees#358221
4Flooded Vegetation#87D19E
5Crops#FFDB5C
7Built Area#ED022A
8Bare Ground#EDE9E4
9Snow / Ice#F2FAFF
10Clouds#C8C8C8
11Rangeland#C6AD8D
Kigali City context: Unlike the whole country, an urban AOI is dominated by Built Area (7) across the three central districts (Nyarugenge, Gasabo, Kicukiro), and this is the class most likely to expand across 2017→2025 as the city grows. Expect substantial Crops (5) and Rangeland (11) in the peri-urban fringe, Trees (2) on hills and wetland margins, and Water (1) / Flooded Vegetation (4) along the valley wetlands (e.g. Nyabugogo). Snow/Ice (9) is absent and Clouds (10) should be near zero in an annual composite.
Sparse values matter: Because valid codes skip numbers (there is no 3 or 6), a naive palette of nine colours applied to min:1,max:11 would mis-assign colours. This guide builds the palette against the true value list so every class shows its correct Esri colour — do not shorten it to a plain 1–11 ramp.

2Add the Kigali City Boundary

Define Kigali City as the Area of Interest. Because Kigali is a first-level administrative unit (a province-equivalent), we use GAUL level-1 — not the level-0 country layer. Two options follow; Option B is recommended for a formal report.

Option A — GAUL level-1 filter Fastest

Filter Rwanda's first-level units down to Kigali. GAUL's spelling for the city varies, so we match any name containing "Kigali" to stay robust.

Kigali City boundary (GAUL level-1)
// GAUL level-1 = provinces / city (Kigali is a province-equivalent)
var adm1 = ee.FeatureCollection('FAO/GAUL/2015/level1');

// Keep Rwanda's units, then match any name containing "Kigali"
// (GAUL stores it as "Ville de Kigali" / "Kigali City" depending on record)
var kigali = adm1
  .filter(ee.Filter.eq('ADM0_NAME', 'Rwanda'))
  .filter(ee.Filter.stringContains('ADM1_NAME', 'Kigali'));

var aoi = kigali.geometry();

print('Kigali unit(s) matched:', kigali.aggregate_array('ADM1_NAME'));
Map.centerObject(aoi, 10);        // zoom 10-11 suits a city
Map.addLayer(kigali, {color: 'black', fillColor: '00000000'}, 'Kigali City');
Check the print: The Console line Kigali unit(s) matched should list exactly one name. If it is empty, the GAUL spelling differs — print all Rwanda unit names with adm1.filter(ee.Filter.eq('ADM0_NAME','Rwanda')).aggregate_array('ADM1_NAME') and copy the exact Kigali string into an ee.Filter.eq.

3Load the Esri LULC Time Series Esri

Load the Esri collection, then pull out one mosaicked image per study year. Each year is stored as an annual image; we filter by date and mosaic to a single layer per year.

Load Esri LULC & build per-year images
// Esri / Impact Observatory 10 m annual land cover
var esri = ee.ImageCollection(
  'projects/sat-io/open-datasets/landcover/ESRI_Global-LULC_10m_TS');

// Helper: get the single land-cover image for a given year, clipped to Kigali
var lulcForYear = function(y){
  var start = ee.Date.fromYMD(y, 1, 1);
  var end   = start.advance(1, 'year');
  return esri.filterDate(start, end)
             .mosaic()
             .rename('lulc')
             .clip(aoi)
             .set('year', y);
};

var lulc2017 = lulcForYear(2017);
var lulc2021 = lulcForYear(2021);
var lulc2025 = lulcForYear(2025);

print('Esri image bands:', lulc2017.bandNames());
Band name check: The Console will show the band renamed to lulc. If a raw call ever shows a different original band name (e.g. b1), the .rename('lulc') above normalises it so the rest of the script is stable. If a year returns an empty mosaic, confirm that year exists in the collection (2017–2025 at time of writing).

4Display Each Year in the Official Esri Colours

Apply the exact Esri class values and hex palette so the three maps look identical to the official product. Because class values are sparse, we pass the full value list and the matching colours.

Esri palette & per-year layers
// Official Esri class values and colours (sparse values!)
var ESRI_VALUES  = [1, 2, 4, 5, 7, 8, 9, 10, 11];
var ESRI_NAMES   = ['Water','Trees','Flooded Veg','Crops',
                    'Built Area','Bare Ground','Snow/Ice','Clouds','Rangeland'];
var ESRI_COLORS  = ['#1A5BAB','#358221','#87D19E','#FFDB5C',
                    '#ED022A','#EDE9E4','#F2FAFF','#C8C8C8','#C6AD8D'];

// Because values are non-contiguous, remap them to 0..8 for a clean palette
var remapVis = function(img){
  return img.remap(ESRI_VALUES, [0,1,2,3,4,5,6,7,8]);
};

var visParams = {min: 0, max: 8, palette: ESRI_COLORS};

Map.addLayer(remapVis(lulc2017), visParams, 'Esri LULC 2017');
Map.addLayer(remapVis(lulc2021), visParams, 'Esri LULC 2021', false);
Map.addLayer(remapVis(lulc2025), visParams, 'Esri LULC 2025');
Why remap for display: A palette in GEE maps colours evenly from min to max. With sparse values (1,2,4,5,…) a direct min:1,max:11 ramp would spread nine colours over eleven slots and mis-colour classes. Remapping the valid values to a tight 0–8 range guarantees each Esri class gets its correct hex. The underlying analysis (area, change, vectors) still uses the original values — we only remap a copy for display.

5Compute Area per Class, per Year

Quantify each class in km². A grouped area reducer counts pixel area by class code in one pass — run it for each year.

Area per class (km²)
// Grouped area (km2) by class value for one LULC image
var areaByClass = function(img, yearLabel){
  var areaImg = ee.Image.pixelArea().divide(1e6)
                 .addBands(img.rename('class'));
  var stats = areaImg.reduceRegion({
    reducer: ee.Reducer.sum().group({groupField: 1, groupName: 'class'}),
    geometry: aoi, scale: 10, maxPixels: 1e13
  });
  print('Area km2 by class - ' + yearLabel, stats);
  return stats;
};

areaByClass(lulc2017, '2017');
areaByClass(lulc2021, '2021');
areaByClass(lulc2025, '2025');
Kigali runs at full 10 m: Because the AOI is a single city (~730 km², not the whole 26,000 km² country), scale: 10 computes comfortably here — a major advantage of the smaller area. Keep scale: 10 for the figures you report. Only raise it (30/100) if you later expand the AOI. State the scale in your methods either way.

6Detect Land-Cover Change (From → To)

Answer RQ3: where did land cover change, and what did it become? We combine two years into a single transition code, so each pixel records its from and to class.

Change: 2017 → 2025 transition map
// Encode a from-to transition: (from * 100) + to
// e.g. rangeland(11) -> built(7) becomes 1107
var transition = lulc2017.multiply(100).add(lulc2025)
                   .rename('transition').clip(aoi);

// Simple "changed vs unchanged" mask (1 where class differs)
var changed = lulc2017.neq(lulc2025).rename('changed').clip(aoi);

Map.addLayer(changed.selfMask(),
  {palette: ['#ff00ff']}, 'Changed pixels 2017-2025', false);

// Focused example: new Built Area (became class 7, was not 7 before)
var newBuilt = lulc2017.neq(7).and(lulc2025.eq(7))
                 .selfMask().clip(aoi);
Map.addLayer(newBuilt, {palette: ['#ED022A']},
  'New Built Area 2017-2025');
Inspect it: Use the Inspector on the transition layer — a value of 1107 means that pixel went from Rangeland (11) to Built Area (7). The "New Built Area" layer isolates urban expansion, the most policy-relevant change for a growing capital like Kigali.
Change vs uncertainty: Some year-to-year differences are classification noise, not real change — especially between spectrally similar classes (Crops ↔ Rangeland). Treat isolated single-pixel changes with caution; trust clustered, spatially coherent change. Say so in your write-up.

7Charts & Graphs

Turn the area statistics into charts. We build a per-year class bar chart and a grouped chart comparing all three years, both printed to the Console (and reused in the app in Step 10).

Area-by-class charts
// Build a FeatureCollection of {class, area, year} for charting
var classFC = function(img, y){
  var areaImg = ee.Image.pixelArea().divide(1e6)
                 .addBands(img.rename('class'));
  var groups = ee.List(areaImg.reduceRegion({
    reducer: ee.Reducer.sum().group({groupField:1, groupName:'class'}),
    geometry: aoi, scale: 30, maxPixels: 1e13
  }).get('groups'));
  return ee.FeatureCollection(groups.map(function(g){
    g = ee.Dictionary(g);
    return ee.Feature(null, {
      'class': g.get('class'),
      'area':  g.get('sum'),
      'year':  y
    });
  }));
};

var fc2017 = classFC(lulc2017, 2017);
var fc2021 = classFC(lulc2021, 2021);
var fc2025 = classFC(lulc2025, 2025);

// Single-year bar chart (2025)
var chart2025 = ui.Chart.feature.byFeature(fc2025, 'class', 'area')
  .setChartType('ColumnChart')
  .setOptions({
    title: 'Land Cover Area by Class - Rwanda 2025',
    hAxis: {title: 'Esri class value'},
    vAxis: {title: 'Area (km2)'},
    legend: {position: 'none'}, colors: ['#3ea34a']
  });
print(chart2025);

// Three-year comparison (merge, then column chart grouped by year)
var allYears = fc2017.merge(fc2021).merge(fc2025);
var compareChart = ui.Chart.feature.groups(allYears, 'class', 'area', 'year')
  .setChartType('ColumnChart')
  .setOptions({
    title: 'Land Cover Area by Class - 2017 vs 2021 vs 2025',
    hAxis: {title: 'Esri class value'},
    vAxis: {title: 'Area (km2)'}, legend: {position: 'top'}
  });
print(compareChart);
Read the charts: The comparison chart is your core RQ2 evidence — each class shows three bars (2017, 2021, 2025) side by side so growth or loss is immediate. Export any chart via the camera icon (SVG/PNG) for your report. To label classes by name instead of value, add an Esri class-name dictionary and map it onto the x-axis.

8Vectorise the Classes (with Colours) Esri

Convert the raster classes into polygons so you can export true vector data. Each polygon carries its class value, class name and Esri hex colour as attributes — so the colours travel with the vectors.

Raster → coloured class polygons
// Vectorise the 2025 classes to polygons
// reduceToVectors groups connected same-value pixels into features
var vectors2025 = lulc2025.rename('class').toInt().reduceToVectors({
  geometry: aoi,
  scale: 10,                 // Kigali is small enough for full 10 m vectorising
  geometryType: 'polygon',
  eightConnected: false,
  labelProperty: 'class',
  maxPixels: 1e13
});

// Attach class name + Esri hex colour to every polygon
var valueToName  = ee.Dictionary({
  '1':'Water','2':'Trees','4':'Flooded Vegetation','5':'Crops',
  '7':'Built Area','8':'Bare Ground','9':'Snow/Ice',
  '10':'Clouds','11':'Rangeland'
});
var valueToColor = ee.Dictionary({
  '1':'#1A5BAB','2':'#358221','4':'#87D19E','5':'#FFDB5C',
  '7':'#ED022A','8':'#EDE9E4','9':'#F2FAFF',
  '10':'#C8C8C8','11':'#C6AD8D'
});

vectors2025 = vectors2025.map(function(f){
  var key = ee.Number(f.get('class')).format('%d');
  return f.set({
    'lc_name': valueToName.get(key, 'Unknown'),
    'color':   valueToColor.get(key, '#000000')
  });
});

// Preview using the stored colour attribute
Map.addLayer(vectors2025.style({
  styleProperty: 'color', width: 1
}), {}, 'Vectorised classes 2025', false);

print('Vector feature count (2025):', vectors2025.size());
Colours in the vectors: Each polygon gets a color attribute holding its Esri hex. In GEE the .style({styleProperty:'color'}) call renders straight from that attribute, and in QGIS you can drive a categorised style from the same lc_name/color field — so your exported vectors keep the official palette wherever they are opened.
City-scale makes this easy: Full 10 m vectorising of an entire country would create hundreds of thousands of polygons and time out — but Kigali City is small enough to vectorise at the native scale: 10 directly. If you still hit a limit (very fragmented classes), raise to scale: 20 or vectorise one class at a time, but for Kigali 10 m should complete.

Honest limit: A published Earth Engine App shows the map, legend, chart and buttons, but it cannot draw a north arrow or a formal scale-and-title print layout — those are cartographic layout features that live in QGIS (Part B). The app is your interactive explorer; QGIS is your map-production studio.

Result: A public link such as https://your-username.users.earthengine.app/view/kigali-esri-land-cover with the year selector, Esri-coloured legend, area chart and download buttons.

12Load & Style the Data in QGIS QGIS

Bring your exported GeoTIFFs and vectors into QGIS. This is where the north arrow, scale bar, formal legend and print layout come from — features a web app cannot provide.

Click by click — load
  1. Download the GeoTIFFs and the vector Shapefile/GeoJSON from your Drive earthengine folder.
  2. In QGIS, drag each .tif and the vector onto the map, or use Layer → Add Layer → Add Raster / Vector Layer.
  3. They load in EPSG:32735 (as exported). Set the project CRS to match: Project → Properties → CRS.
  4. Optional live backdrop: Layer → Add Layer → Add ArcGIS REST Server Layer, paste https://ic.imagery1.arcgis.com/arcgis/rest/services/Sentinel2_10m_LandCover/ImageServer to stream the Esri service.
Click by click — style the raster in Esri colours
  1. Right-click the land-cover raster → Properties → Symbology.
  2. Set Render type to Paletted/Unique values.
  3. Click Classify — QGIS lists the class values (1,2,4,5,7,8,9,10,11).
  4. Double-click each colour swatch and set the exact Esri hex from the class table (e.g. Built Area → #ED022A). Label each with its class name.
  5. Apply → OK. Or skip all of this by loading a .qml style file (next step), which sets values, colours and labels in one click.

  1. Save the block above as kigali_esri_lulc.qml in the same folder as your raster.

14Print Layout — North Arrow, Scale Bar, Legend QGIS

This is the deliverable a report needs: a composed map with a north arrow, scale bar, title and legend. QGIS Print Layout is the tool that produces it.

Click by click — build the layout
  1. Style your land-cover layer and add the Kigali City boundary on top.
  2. Project → New Print Layout. Name it Kigali LULC 2025.
  3. Add Item → Add Map, then drag a rectangle to place the map frame. Pan/zoom via Item Properties → set scale.
  4. Add Item → Add North Arrow, draw it in a corner. Pick an arrow style in Item Properties. (It auto-orients to the map's north.)
  5. Add Item → Add Scale Bar; set Units to kilometres and style to match.
  6. Add Item → Add Legend; it reads your Esri class colours and labels automatically. Untick Auto update to hand-edit entries.
  7. Add Item → Add Label for the title (e.g. "Kigali City Land Cover 2025 — Esri 10 m Sentinel-2") and a second label for the data source / date.
  8. Layout → Export as Image / PDF / SVG for your report.
Multi-year figure: To show 2017, 2021 and 2025 side by side, add three map frames to one layout, each locked to a different layer via Item Properties → Layers → Lock layers. One north arrow, one scale bar and a shared legend serve all three panels — a clean change-over-time figure.

15Put Charts & Graphs on the Map QGIS

You asked for graphs in the map. There are two clean ways to do this in QGIS — a chart embedded in the print layout, or live diagrams drawn on the features themselves.

Option A — Chart picture in the Print Layout Simplest

Click by click
  1. Export your area-by-class chart from GEE (Step 7, camera icon → PNG/SVG), or make one in a spreadsheet from the exported area table.
  2. In the Print Layout: Add Item → Add Picture → browse to the chart image.
  3. Position it beside the map frame; resize as needed. It prints as part of the composed map.

Option B — Diagrams drawn on features (data-driven)

Click by click
  1. Load a polygon layer with per-feature numeric fields — e.g. district boundaries joined to a table of class areas per district (compute district areas in GEE with reduceRegions).
  2. Layer Properties → Diagrams → enable Pie chart or Bar chart.
  3. Add the class-area attributes as diagram categories and give each the matching Esri colour.
  4. Each district now shows a live pie/bar of its land-cover mix, directly on the map. Add this layer to the Print Layout as usual.
Which to use: Option A is fastest for a single national chart next to the map. Option B is the stronger analytical figure — a per-district pie chart of land-cover composition reads as a proper thematic map and pairs naturally with your change results. Both live only in QGIS, not in the GEE app.

✓Full Combined Script

The complete, ready-to-run GEE script combining every step. Paste into a single Code Editor file to run the whole analysis and launch the app.

kigali_esri_lulc_full.js
// ============================================================
// RWANDA LULC - ESRI 10 m SENTINEL-2 LAND COVER (2017/2021/2025)
// Maps + Area + Change + Vectors + Export + App w/ downloads
// ============================================================

// --- 1. Boundary: Kigali City (GAUL level-1; swap for uploaded asset) ---
var adm1 = ee.FeatureCollection('FAO/GAUL/2015/level1');
var kigali = adm1
  .filter(ee.Filter.eq('ADM0_NAME', 'Rwanda'))
  .filter(ee.Filter.stringContains('ADM1_NAME', 'Kigali'));
var aoi = kigali.geometry();
Map.centerObject(aoi, 10);
Map.addLayer(kigali, {color:'black', fillColor:'00000000'}, 'Kigali City');

// --- 2. Esri LULC time series -> per-year images ---
var esri = ee.ImageCollection('projects/sat-io/open-datasets/landcover/ESRI_Global-LULC_10m_TS');
var lulcForYear = function(y){
  var s = ee.Date.fromYMD(y,1,1), e = s.advance(1,'year');
  return esri.filterDate(s,e).mosaic().rename('lulc').clip(aoi).set('year',y);
};
var lulc2017 = lulcForYear(2017);
var lulc2021 = lulcForYear(2021);
var lulc2025 = lulcForYear(2025);

// --- 3. Esri palette (sparse values -> remap for display) ---
var ESRI_VALUES = [1,2,4,5,7,8,9,10,11];
var ESRI_COLORS = ['#1A5BAB','#358221','#87D19E','#FFDB5C','#ED022A','#EDE9E4','#F2FAFF','#C8C8C8','#C6AD8D'];
var remapVis = function(img){ return img.remap(ESRI_VALUES, [0,1,2,3,4,5,6,7,8]); };
var visParams = {min:0, max:8, palette:ESRI_COLORS};
Map.addLayer(remapVis(lulc2017), visParams, 'Esri LULC 2017');
Map.addLayer(remapVis(lulc2021), visParams, 'Esri LULC 2021', false);
Map.addLayer(remapVis(lulc2025), visParams, 'Esri LULC 2025');

// --- 4. Area per class per year ---
var areaByClass = function(img, lbl){
  var a = ee.Image.pixelArea().divide(1e6).addBands(img.rename('class'));
  print('Area km2 - '+lbl, a.reduceRegion({
    reducer: ee.Reducer.sum().group({groupField:1,groupName:'class'}),
    geometry: aoi, scale:10, maxPixels:1e13}));
};
areaByClass(lulc2017,'2017'); areaByClass(lulc2021,'2021'); areaByClass(lulc2025,'2025');

// --- 5. Change 2017 -> 2025 ---
var changed = lulc2017.neq(lulc2025).selfMask().clip(aoi);
Map.addLayer(changed, {palette:['#ff00ff']}, 'Changed 2017-2025', false);
var newBuilt = lulc2017.neq(7).and(lulc2025.eq(7)).selfMask().clip(aoi);
Map.addLayer(newBuilt, {palette:['#ED022A']}, 'New Built 2017-2025');

// --- 6. Chart FC + single-year chart ---
var classFC = function(img,y){
  var a = ee.Image.pixelArea().divide(1e6).addBands(img.rename('class'));
  var g = ee.List(a.reduceRegion({reducer:ee.Reducer.sum().group({groupField:1,groupName:'class'}),
    geometry:aoi, scale:30, maxPixels:1e13}).get('groups'));
  return ee.FeatureCollection(g.map(function(d){ d=ee.Dictionary(d);
    return ee.Feature(null,{'class':d.get('class'),'area':d.get('sum'),'year':y}); }));
};
var fc2017=classFC(lulc2017,2017), fc2021=classFC(lulc2021,2021), fc2025=classFC(lulc2025,2025);
var chart2025 = ui.Chart.feature.byFeature(fc2025,'class','area')
  .setChartType('ColumnChart').setOptions({title:'Area by Class - 2025',
    hAxis:{title:'Class'}, vAxis:{title:'km2'}, legend:{position:'none'}, colors:['#3ea34a']});
print(chart2025);
var allYears = fc2017.merge(fc2021).merge(fc2025);
print(ui.Chart.feature.groups(allYears,'class','area','year')
  .setChartType('ColumnChart').setOptions({title:'Area by Class - 2017/2021/2025',
    hAxis:{title:'Class'}, vAxis:{title:'km2'}, legend:{position:'top'}}));

// --- 7. Vectorise 2025 with colours ---
var vectors2025 = lulc2025.rename('class').toInt().reduceToVectors({
  geometry:aoi, scale:10, geometryType:'polygon', eightConnected:false,
  labelProperty:'class', maxPixels:1e13});
var nameD = ee.Dictionary({'1':'Water','2':'Trees','4':'Flooded Vegetation','5':'Crops',
  '7':'Built Area','8':'Bare Ground','9':'Snow/Ice','10':'Clouds','11':'Rangeland'});
var colD = ee.Dictionary({'1':'#1A5BAB','2':'#358221','4':'#87D19E','5':'#FFDB5C',
  '7':'#ED022A','8':'#EDE9E4','9':'#F2FAFF','10':'#C8C8C8','11':'#C6AD8D'});
vectors2025 = vectors2025.map(function(f){ var k=ee.Number(f.get('class')).format('%d');
  return f.set({'lc_name':nameD.get(k,'Unknown'),'color':colD.get(k,'#000000')}); });
Map.addLayer(vectors2025.style({styleProperty:'color', width:1}), {}, 'Vectors 2025', false);

// --- 8. Exports ---
Export.image.toDrive({image:lulc2025.toInt(), description:'Kigali_EsriLULC_2025', folder:'earthengine',
  fileNamePrefix:'kigali_esri_lulc_2025', region:aoi, scale:10, crs:'EPSG:32735', maxPixels:1e13});
Export.table.toDrive({collection:vectors2025, description:'Kigali_EsriLULC_2025_SHP', folder:'earthengine',
  fileNamePrefix:'kigali_esri_lulc_2025_vector', fileFormat:'SHP'});
Export.table.toDrive({collection:vectors2025, description:'Kigali_EsriLULC_2025_GeoJSON', folder:'earthengine',
  fileNamePrefix:'kigali_esri_lulc_2025_vector', fileFormat:'GeoJSON'});

// --- 9. App UI with legend, year select, chart, downloads ---
Map.setControlVisibility({layerList:true});
var panel = ui.Panel({style:{width:'340px', padding:'12px'}});
panel.add(ui.Label('Rwanda Esri Land Cover Explorer', {fontSize:'20px', fontWeight:'bold', color:'#3ea34a'}));
panel.add(ui.Label('Esri 10 m Sentinel-2 LULC | 2017 . 2021 . 2025', {fontSize:'12px', color:'gray'}));
var legend = ui.Panel({style:{padding:'8px 0 0 0'}});
legend.add(ui.Label('Classes', {fontWeight:'bold', fontSize:'13px'}));
var LN=['Water','Trees','Flooded Veg','Crops','Built Area','Bare Ground','Snow/Ice','Clouds','Rangeland'];
ESRI_COLORS.forEach(function(c,i){ legend.add(ui.Panel([
  ui.Label('',{backgroundColor:c,padding:'8px',margin:'0 6px 0 0',border:'1px solid #999'}),
  ui.Label(LN[i],{margin:'0',fontSize:'13px'})], ui.Panel.Layout.Flow('horizontal'))); });
panel.add(legend);
var imgs = {'2017':lulc2017, '2021':lulc2021, '2025':lulc2025};
panel.add(ui.Label('Select year:', {margin:'10px 0 2px', fontSize:'13px'}));
panel.add(ui.Select({items:['2017','2021','2025'], value:'2025', onChange:function(y){
  Map.layers().reset();
  Map.addLayer(remapVis(imgs[y]), visParams, 'Esri LULC '+y);
  Map.addLayer(kigali, {color:'black', fillColor:'00000000'}, 'Boundary');
}}));
panel.add(chart2025);
panel.add(ui.Label('Download data:', {fontWeight:'bold', margin:'10px 0 2px'}));
panel.add(ui.Button({label:'Download 2025 raster (GeoTIFF)', onClick:function(){
  print('Raster URL:', lulc2025.toInt().getDownloadURL({name:'kigali_esri_lulc_2025',
    region:aoi, scale:100, crs:'EPSG:32735', filePerBand:false})); }}));
panel.add(ui.Button({label:'Download 2025 vectors (GeoJSON)', onClick:function(){
  print('Vector URL:', vectors2025.getDownloadURL({format:'GeoJSON',
    filename:'kigali_esri_lulc_2025_vector'})); }}));
ui.root.add(panel);

Known limitations

  • Accuracy ~75 %: some pixels are misclassified; report this and treat marginal change cautiously.
  • Classifier variability: apparent change between years can be model noise, especially Crops ↔ Rangeland; trust spatially coherent change.
  • Sparse class values: must be handled explicitly in palettes and styles (done throughout this guide).
  • Vectorising is feasible at 10 m for Kigali: the small city AOI runs at native resolution; only a national AOI would need a coarser scale.
  • Tool division: north arrow, scale bar, print layout and on-map graphs are QGIS features — the GEE app cannot produce them.
